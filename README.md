# 🤖 ChatBot con integración a Google Calendar

Este es un proyecto de ChatBot desarrollado en Python con FastAPI que permite al usuario:

- Añadir eventos a su calendario.
- Mostrar los eventos próximos.
- Eliminar eventos existentes.
- Responder preguntas frecuentes.
- Todo a través de una interfaz tipo chat simple y directa.

## 🚀 Funcionalidades

- 📅 Integración con Google Calendar.
- 💬 Interfaz de chat sencilla.
- ❓ Preguntas frecuentes precargadas.
- 🔐 Uso seguro de credenciales mediante variables de entorno.
